### 已定的关键技术决策（勿随意推翻）

1. **数据库只走 Rust 侧 `rusqlite`**（bundled SQLite），不用 `tauri-plugin-sql`；不用 sqlx。
2. **启动用 `CreateProcessW`** 直调：`lpApplicationName`=路径、`lpCommandLine`=引号路径+原样参数、`lpCurrentDirectory`=工作目录；不走 shell。

7. **COM 调用（IShellLinkW、IShellItemImageFactory）隔离到独立 STA 线程**，`oneshot` 回传。
8. **封面/图标复制到 `app_data_dir/covers|icons`，DB 存相对路径**，asset protocol 只放行这两个目录。

### 新增踩坑

- ⚠️ **`IShellLinkW::GetPath` 是 3 个参数**（`&mut [u16]`, `*mut WIN32_FIND_DATAW`, `u32`），中间的 FIND_DATA 在只带 `SLGP_RAWPATH` 时传 `std::ptr::null_mut()`。
- ⚠️ **`SLGP_RAWPATH.0` 是 `i32`，接口要 `u32`** → 需 `as u32`。
- ⚠️ **组件语法里不能裸写尖括号**：`Option<Game>` 会被当成 `<Game>` 组件报错。改写或转义。

## 追加：740 提权兜底（用户选了方案 B）

用户想让应用能启动 TCLS/client.exe 这类要求管理员的 exe。给了 A（整个应用提权，会让所有游戏继承
管理员权限，Valorant 的 Vanguard 会拒绝提权进程）与 B（只对 740 的 exe 弹 UAC）两个方案，用户选 **B**。

**实现**（`launcher/launch.rs` 重构）：
- `launch()` → `try_create_process()`（原 CreateProcessW 逻辑，错误原样上抛 windows Error）
- 返回 740 → `launch_elevated()`：`ShellExecuteExW(runas)` + `SEE_MASK_NOCLOSEPROCESS`，
  UAC 同意后拿到进程句柄 → `GetProcessId` + `GetProcessTimes` → **计时追踪照常**
- UAC 点「否」（1223 ERROR_CANCELLED）→ 报「已取消管理员授权，程序未启动」
- hProcess 意外为空 → 明确报「时长将不会被统计」（不静默丢数据）
- 应用本身**不提权**（铁律 #6 不变），普通 asInvoker 游戏行为完全不变

**文档**：架构文档 ADR-02 补「740 兜底」说明（本地 + 云端）。
**校验**：134 passed / 0 failed，clippy 零警告，tauri build 通过（MSI 3.57 / NSIS 2.57 MiB）。
